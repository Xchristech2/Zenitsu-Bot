## ⚙️ Features  

✨ Tag all group members  
🔒 Admin-only commands  
🎮 Built-in games (Tic-Tac-Toe, Trivia, etc.)  
🔊 Text-to-Speech system  
🖼️ Sticker & media tools  
🚫 Anti-link protection  
⚠️ Warning & moderation system  

---

## 📖 About  

QUEEN LUCY V3 helps WhatsApp admins manage large groups easily.  
It uses the **Baileys library** and supports **multi-device connection**.  

- Lightweight & fast ⚡  
- Easy to customize 🛠️  
- QR-based authentication 📱
