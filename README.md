🔐 Step 3: Pair Your Bot

After deploying the bot, you can connect your WhatsApp account using the Pair Code.

<div align="center"><a href="https://gaaju-ultra-pair-ljtv.onrender.com">
<img src="https://img.shields.io/badge/PAIR%20NOW-FF1493?style=for-the-badge&logo=whatsapp&logoColor=white"/>
</a></div>📱 How To Pair

1. Deploy ZENITSU BOT.
2. Open the PAIR NOW website.
3. Enter your WhatsApp number with country code.
4. Click Get Pairing Code.
5. Open WhatsApp → Linked Devices → Link a Device.
6. Enter the pairing code shown on the pair site.
7. Wait for the bot to connect.

«⚠️ Keep your pairing/session information private. Do not share it with anyone.»

📖 About

ZENITSU BOT helps WhatsApp admins manage groups easily while providing entertainment and useful automation tools.

It uses the Baileys library and supports Multi-Device WhatsApp connection.

- Lightweight & fast ⚡
- Easy to customize 🛠️
- Pair-code authentication 🔐
- Multi-device support 📱

---

🛠️ Installation

📌 Requirements

- Node.js
- Git

⚡ Setup

git clone https://github.com/Xchristech2/Zenitsu-Bot.git
cd Zenitsu-Bot
npm install
node index.js

🔐 Authentication

After starting the bot, use the Pair Now button above to generate your WhatsApp pairing code.

Never share your session ID or pairing credentials with anyone.
